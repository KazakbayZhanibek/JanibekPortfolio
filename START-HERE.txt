ПОРТФОЛИО ЖАНИБЕКА — ЖИВОЙ ПЛАКАТ

Запуск
1. Дважды нажмите start-portfolio.cmd.
2. Откроется браузер. Окно терминала оставьте открытым.
3. Для остановки нажмите Ctrl+C в терминале.
Требуется Node.js 22+; зависимости уже установлены.
Если основной порт занят, Vite выберет следующий и покажет адрес.

Команды из папки проекта
npm install       — установка зависимостей
npm run dev       — локальный запуск
npm run build     — проверка TypeScript и сборка двух HTML-входов в dist/
npm run preview   — просмотр готовой сборки

Локальные страницы
http://127.0.0.1:5173/ — основной сайт в выбранном направлении poster.
http://127.0.0.1:5173/design-preview.html — сравнение трёх работающих вариантов.
Добавьте к design-preview.html ?view=notebook, ?view=editorial или ?view=poster,
чтобы открыть один вариант. Они намеренно сохранены, а не брошены после выбора.
Vite собирает и index.html, и design-preview.html. При другом порте используйте
адрес из терминала. Публичный адрес и порядок публикации указаны ниже.

Что редактировать
src/content.ts — имя, возраст, общие RU/EN тексты биографии, контакты и проекты.
src/App.tsx — переключение тем и часть двуязычных заголовков и текстов этих тем.
profile.github — предоставленный Жанибеком публичный аккаунт:
https://github.com/KazakbayZhanibek. Основной App читает ссылку из этого поля.
profile.email / profile.telegram — пока null; заполняйте только одобренными данными.
projects — названия, категории, ссылки на исходники и доступные публичные сайты.
Это личный сайт о Жанибеке, не страница кандидата или продажи услуг. Резюме убрано.
src/components/project-exhibits.tsx — обложки и просмотр компьютерных/мобильных снимков.
src/components/project-dialog.tsx — просмотр проекта с закреплёнными управлением и заголовком.
public/images/projects/ — десять WebP-снимков и соседние .webp.json с происхождением.
public/images/sources.json — источники снимков, учебные данные и ограничения.
src/index.css — Tailwind и общие стили; цвета листов также заданы в src/App.tsx.
Цвета окон со скриншотами: .project-dialog[data-project] в src/index.css.
У каждого проекта своя палитра; основной плакат и исходные снимки не перекрашиваются.
src/fonts.css — локальные шрифты Unbounded и Prata.
src/previews/ — сохранённые notebook, editorial и poster; отдельный HTML-вход —
design-preview.html. Основной сайт реализован в src/App.tsx.

Содержание
По умолчанию открыт лист «Обо мне»: знакомство, Caspian University / 3 курс /
Алматы и история первых курсов в 10 классе. «Вне экрана» — прогулки, горы,
природа, осень и зима. «Мои проекты» — поддерживающая часть личной истории.
Переключатель тем мгновенно заменяет целый цветной лист, а не прокручивает
длинную страницу. Выбранная тема обозначена явно; кнопки доступны с клавиатуры.
На листе проектов сначала виден компактный список; можно включить галерею
и фильтровать по категориям.
Сертификаты будут предоставлены позже: пока нет вымышленных названий, значков,
точного счётчика или пустого раздела. Фото человека тоже не подменяется стоковым.
RANO Comfort, Тенге Трекер, Жан-Плов, Bulbul Forum и Калории EveryDay заменили
вымышленные примеры. Откройте работу: можно переключить компьютер/телефон,
скачать снимок, перейти к исходникам или доступному публичному сайту.
Есть переход к предыдущему/следующему проекту; Escape закрывает просмотр,
после закрытия фокус возвращается к кнопке проекта.
Снимки Bulbul и Калорий сняты локально с учебными данными. Тенге использует
встроенные демо-данные без доступа к личной таблице. Калории — совместный проект.
Обновляя снимки, сохраняйте <id>-desktop.webp (1440×1000) и
<id>-mobile.webp (390×844), а также sources.json и соседние .webp.json.
Не придумывайте личные истории, увлечения или достижения.

Изображения, шрифты и происхождение
public/previews/ содержит три WebP-снимка вариантов и их .webp.json sidecar-файлы.
public/previews/sources.json — источники этих снимков, шрифтов и стокового фото.
public/previews/assets/ — локальные Unbounded, Prata, их OFL-лицензии и mountains.jpg.
Стоковое фото гор лицензировано по Unsplash License и используется только
в альтернативе editorial. Это не личная фотография Жанибека, не его работа
и не подтверждение места его прогулок. В основном poster фотографии человека нет.
Manrope и IBM Plex Mono поставляются локально через Fontsource-пакеты.
Записи происхождения покрывают 14 растров: 10 проектов, 3 превью и 1 стоковое фото.

Публикация
Адрес: https://kazakbayzhanibek.github.io/JanibekPortfolio/
Репозиторий: https://github.com/KazakbayZhanibek/JanibekPortfolio
В Settings → Pages выбран Source: GitHub Actions, не main / (root).
При push в main workflow .github/workflows/deploy-pages.yml выполняет npm ci,
npm run build и публикует только dist/ через официальные Pages Actions.
Повторный запуск доступен в Actions → Deploy portfolio to GitHub Pages.
Не публикуйте исходный index.html напрямую: браузер не исполняет src/main.tsx.
Относительная base в Vite и import.meta.env.BASE_URL сохраняют пути к ресурсам,
снимкам и страницам вариантов внутри /JanibekPortfolio/.
На другом статическом хостинге также размещайте содержимое dist/.
Нет сервера сбора заявок и фиктивной формы. GitHub уже доступен; ссылки на почту
и Telegram появятся только после заполнения соответствующих полей.

Стек
React + TypeScript + Vite + Tailwind CSS.
Официальные shadcn/ui Button/Dialog и адаптированный Aceternity UI 3D Card.
Ограниченный наклон доступен только в галерее с мышью; на touch, при reduced-motion
и в списке он выключен. Hero BlurFade в текущем poster не используется.
Unbounded — крупные заголовки, Manrope — основной текст; шрифты локальные.
